# Analysis and replay methodology

Two deterministic, LLM-free post-draft systems: grading
(`packages/domain/src/analysis.ts`, v`1.0.0`) and replay
(`packages/domain/src/replay.ts`, v`1.0.0`). Decisions: ADR 0015
(analysis/history) and ADR 0016 (replay/sharing).

## Grade composite (5 components, 0–100, A–F)

Weights sum to 1 via largest-remainder at 6 dp (ADR 0015 D3):

| Component           | Weight | Sketch                                                                                                                                   |
| ------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `valueCaptured`     | 0.25   | mean `adpValueNorm = 0.5 + clamp(adp − overallPick, −24..24)/48` vs pool                                                                 |
| `projectedStrength` | 0.30   | POINTS: Σ season fantasy points; CATEGORIES: mean category win-probability vs replacement-built baseline (logistic, 0.85-ceiling family) |
| `rosterBalance`     | 0.15   | `1 − 0.5·Gini(posCounts) − 0.2·benchWaste/total`; 0 on illegal picks                                                                     |
| `risk`              | 0.15   | `mean(safety)`, `safety = 1 − (0.6·injuryRisk + 0.25·width + 0.15·(1 − roleSecurity))`, banded LOW/MEDIUM/HIGH                           |
| `scoringFit`        | 0.15   | punt-leak + category-emphasis; exactly 1.0 in points leagues                                                                             |

Overall `draftScore = round(100·clamp(Σ w·norm, 0, 1), 1)`; letters
A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, F < 60. All contributions clamp to
0–100 with NaN/Infinity guards. Points and category leagues share
weights but use different strength sources — cross-format comparison is
labeled invalid. Age is neutral in redraft, youth-biased in dynasty.
(ADR 0015 D3; `packages/domain/src/analysis.ts:529-571,1190-1229`)

## 2000-run standing simulation

`2000` seeded runs (offline evaluation count, vs 250 live) derive seeds
from FNV1a32(`simulationSeed:analysisVersion:projectionRunId`) →
per-pick SHA-256 → `mulberry32` softmax over ADP/projection/tendency
(temperature 1.2). The baseline is `replacementTeamTotals` — a synthetic
league (median starters × 11 opponents), explicitly labeled "vs
replacement-built opponent", never presented as real opponent rosters or
a user percentile without a real population. (ADR 0015 D3–D4)

## Analysis input identity

Canonical input is built solely from immutable evidence at
`DRAFT_COMPLETED` (settings snapshot, effective event log after undo
resolution, materialized rosters, pinned projection/ADP runs with
provenance, preference snapshot, engine/seed/type versions, player
universe, active admin-approved signals/overrides). `generatedAt` is
excluded so identical inputs hash identically. Append-only versioning:
`@@unique([draftId, analysisVersion, inputChecksum])` returns the cached
row; new versions add rows. (ADR 0015 D1–D2)

## Replay reduction + integrity

`replayToSequence(events, teamCount, uptoSequence)` is a pure
sequence-sliced reduction: effective selections (keepers included,
undone excluded), per-team lists, cursor, lifecycle flags, and a
SHA-256 checksum over canonicalized selections. Snake numbering counts
effective picks only; undo removes the `causationEventId` selection and
decrements the cursor, so alternate histories replay exactly. Final
state is differential-tested byte-equal to `draft.ts:replayFromEvents` —
there is exactly one replay interpretation. Bounded at 5000 events;
unknown state-changing event types and malformed rows (gaps, duplicates,
corrupt undos, illegal slots) return typed `ReplayError`s rendered as
`integrity: FAIL`, never as trustworthy state. (ADR 0016 R1–R2;
`docs/architecture/replay-and-sharing.md` §1–§3)

Analysis is never regenerated by replay or sharing, and sharing or
revocation never mutates the owner's result (ADR 0016 R6).
